Workspace MCP

Workspace MCP は、運営者（Satoshi Hirose）が自分自身の Google アカウントを AI アシスタントから操作するための個人用ツールです。一般の利用者向けのサービスではありません。

Workspace MCP is a personal tool that lets its operator (Satoshi Hirose) access the operator's own Google accounts from an AI assistant. It is not offered as a service to the public.

プライバシーポリシー / Privacy Policy

  1. 取得する情報：Google OAuth で許可された範囲の Google アカウントのデータ（Gmail、カレンダー、ドライブ、ドキュメント、スプレッドシート、スライド、フォーム、タスク、連絡先、Chat、Apps Script など）。
  2. 利用目的：運営者本人が依頼した操作（閲覧・作成・編集など）を実行するためだけに利用します。
  3. 第三者提供：取得したデータを販売・共有・広告目的で利用することはありません。
  4. 保存：OAuth の認証情報は運営者が管理するサーバー上にのみ保存されます。
  5. 削除：Google アカウントのアクセス管理からいつでもアクセス権を取り消せます。

This app accesses Google user data only within the scopes granted via OAuth, solely to perform actions requested by the operator. Data is never sold, shared with third parties, or used for advertising. Credentials are stored only on a server controlled by the operator. Access can be revoked at any time from Google Account permissions.

Workspace MCP's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
